# EntityData

A single extracted entity with its associated metadata. Contains the entity text, type, character offsets (if requested), and lookup information such as entity ID and name from FactSet's concordance database. Example fields include text, type, startChar, endChar, entityId, lookupText, lookupUrl, and associatedOrgs.
