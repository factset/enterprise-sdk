# Ids

The requested list of security identifiers. Accepted ID types include Market Tickers, SEDOL, ISINs, CUSIPs, or FactSet Permanent IDs.<p><strong>IDs limit</strong> = 20 per non-batch request and 1000 per batch request.</p><p> Make Note, <strong>GET</strong> method URL request lines are limited to a total length of 8192 bytes (8 KB). For requests with large numbers of identifiers that may exceed this limit, use the corresponding <strong>POST</strong> method where available.</p>
