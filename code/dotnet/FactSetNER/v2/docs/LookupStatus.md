# FactSet.SDK.FactSetNER.Model.LookupStatus
Status of an entity lookup operation. 'success' indicates the entity was found and resolved to a FactSet entity ID. 'noMatch' indicates the entity text did not match any FactSet entity. 'failed' indicates the lookup service was unavailable or the lookup operation failed.
